# 성경 앞의 우리 — Together Before Scripture

**함께 읽고, 함께 묻다.**

「성경 앞의 우리」는 성경을 읽고 그 메시지를 함께 탐구하기 위한 비상업적 프로젝트입니다. 한국어 성경 번역과 KJV 영문 읽기용 편집본, 책별 해설을 단계적으로 공개하고, 중요한 판단 근거와 수정 이력을 기록합니다.

- [성경 해설](https://gladbinah.github.io/commentary/)

- [YouTube 「성경 앞의 우리」](https://www.youtube.com/@GladBinah)

## 공개 및 검토

현재 KJV 1769, Scrivener 1894 Textus Receptus, 개역한글판(1961)의 참고 본문을 공개하고 있습니다. 독립 한국어 번역문과 KJV 영문 읽기용 편집본, 책별 해설은 승인된 범위부터 차례로 출판할 계획입니다.

본문의 해석과 번역에 관한 질문, 근거 있는 비판과 수정 제안은 [GitHub Issues](https://github.com/GladBinah/gladbinah.github.io/issues)를 통해 환영합니다.
