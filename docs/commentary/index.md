# 성경 주석

**성경을 함께 읽고, 질문하고, 근거를 살펴보는 장기 프로젝트**

각 책을 내용상 자연스러운 단위로 나누어 역사적·문법적·문학적 의미를 먼저 검토하고, 필요한 경우 정경 전체와의 연결 및 신학적 의미를 살펴봅니다. 제가 먼저 성경을 읽고 정리한 내용을 나누되, 그것을 최종적인 정답으로 제시하지 않겠습니다. 독자들의 질문과 타당한 비판을 검토하고 중요한 변경 근거를 기록하겠습니다.

**현재는 성경 번역 프로젝트를 먼저 진행하고 있으며, 책별 주석서는 아직 이 사이트에 공개하지 않았습니다.** 주석을 작성할 때 적용할 관점은 [성경 해석과 주석 작성의 기본 원칙](principles.md)에 정리했습니다.
