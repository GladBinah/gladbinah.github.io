# 참고 배경 자료

성경의 역사적·문화적·문학적 배경과 관련 문헌을 이해하는 데 도움이 되는 자료를 구약과 신약으로 나누어 소개합니다. 이러한 자료는 본문을 해석할 때 참고할 수 있지만, 개별 자료의 주장 전체를 이 프로젝트의 결론으로 채택한다는 의미는 아닙니다.

- [구약 배경 자료](../references.md) — 모세오경과 여호수아 등 구약성경의 역사적 배경 및 고대 문헌과의 관계
- [신약 배경 자료](../nt-resources.md) — 신약성경의 역사적·문화적 배경, 사본 전승 및 초대교회 관련 자료

자료는 내용을 검토한 뒤 필요한 범위에서 추가하겠습니다.
