# KJV 한글성경 해설

「성경 앞의 우리」의 책별 성경 해설을 구약과 신약으로 나누어 안내합니다. 각 해설은 본문의 역사적·문법적·문학적 의미를 우선 검토하고, 필요한 경우 정경적·신학적 의미를 살핍니다. 승인된 읽기 단위부터 순차적으로 공개합니다.

- [KJV 한글성경 해설: 구약](../old-testament/index.md)
- [KJV 한글성경 해설: 신약](../new-testament/index.md)

## 현황

현재는 성경 번역 프로젝트를 우선 진행하고 있으며, **구약·신약의 책별 해설 본문은 아직 이 홈페이지에 공개하지 않았습니다.** 이후 각 성경책에서 검토·승인된 읽기 단위부터 차례로 공개하겠습니다.
