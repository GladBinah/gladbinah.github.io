# New Testament Translation Index

No translated biblical books have been published yet. Once a passage is reviewed and approved, this page will link to the relevant Korean Markdown text, its book-specific version, coverage, and translation notes.

!!! info "Book-specific versioning"
    Each biblical book will have its own version number. Translation texts and review records are maintained separately so that major decisions and subsequent revisions remain traceable.

The translation itself will be published in Korean. The English site provides the project's objectives, methods, and review information.
