# KJV 한글성경

「성경 앞의 우리」에서 준비하는 독립 한국어 성경 번역문을 구약과 신약으로 나누어 소개합니다. 각 성경책의 본문은 충분한 검토와 승인을 마친 범위부터 차례로 공개하며, 중요한 번역 선택과 수정 근거도 함께 기록합니다.

- [KJV 한글성경: 구약](../old-testament/index.md)
- [KJV 한글성경: 신약](../new-testament/index.md)

## 작업 현황

현재 공개판은 [창세기 1:1–2:25 (한국어 0.2.1 / 영어 0.2.0)](../old-testament/genesis.md)입니다. 독립 한국어 번역문, 영어 KJV 읽기용 편집본, 원어 학습 자료와 번역 기록을 함께 제공합니다. 새 소단원은 검토와 승인 후 순차적으로 추가하며 신약 본문은 아직 공개하지 않았습니다.
