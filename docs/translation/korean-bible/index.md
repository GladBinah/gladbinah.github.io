# KJV 한글성경

「성경 앞의 우리」에서 준비하는 독립 한국어 성경 번역문을 구약과 신약으로 나누어 소개합니다. 각 성경책의 본문은 충분한 검토와 승인을 마친 범위부터 차례로 공개하며, 중요한 번역 선택과 수정 근거도 함께 기록합니다.

- [KJV 한글성경: 구약](../old-testament/index.md)
- [KJV 한글성경: 신약](../new-testament/index.md)

## 작업 현황

번역 원칙과 참조 성경 자료는 이미 공개했습니다. 독립 한국어 번역문과 KJV 영문 읽기용 편집본은 아직 검토·준비 단계에 있으며, **구약·신약 모두 승인·공개된 독립 번역 본문이 없습니다.** 신약 번역을 우선 진행하고 구약 번역도 장기적으로 병행할 계획입니다. 첫 본문이 승인되면 각 성경책의 출판 범위, 버전, 중요한 번역 결정 기록을 이곳에서 확인할 수 있도록 하겠습니다.
