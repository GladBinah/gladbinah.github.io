# KJV 한글성경: 구약

구약성경의 번역도 앞으로 책별로 진행할 계획입니다. 신약성경 번역과 함께, 구약을 읽고 주석을 작성하면서 중요한 본문 문제를 검토해 나가겠습니다. **아직 승인·공개된 구약 번역문은 없습니다.**

## 번역의 출발점

구약에서는 **마소라 본문(Masoretic Text, MT)**을 기본 출발점으로 삼고, 공개된 [Westminster Leningrad Codex(WLC)](../../source-texts/wlc/index.md)를 주요 히브리어 참조 자료로 사용합니다. KJV도 중요한 대조 번역으로 활용합니다. 다만 **칠십인역(Septuagint, LXX)**과 **사해사본(Dead Sea Scrolls, DSS)**이 의미 있는 다른 독법을 전한다면 해당 구절의 문맥, 원어와 사본 증거를 비교하여 판단하겠습니다. 예를 들어 신명기 32:8처럼 서로 다른 본문 전통의 차이가 해석에 영향을 주는 곳은 주요 대안과 판단 근거를 기록합니다.

본문에 대한 해석과 번역을 혼동하지 않도록, KJV의 표현과 다른 히브리어 독법을 반영한 제안 번역은 구별하겠습니다. 번역이 완성된 책부터 **번역 범위, 책별 버전, 중요한 수정 내역 및 관련 주석**을 연결할 예정입니다.

!!! info "책별로 천천히 공개합니다"
    구약 전체의 완성 일정이나 번역 순서를 미리 확정하지 않았습니다. 각 책의 본문을 충분히 검토하고 승인한 뒤 공개하며, 영어 KJV 읽기용 편집본과 한국어 번역문은 독립적인 버전과 편집 기록으로 관리합니다.
