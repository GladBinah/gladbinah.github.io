# KJV 한글성경: 구약

구약성경을 책별·내용 단위별로 번역하고 검토한 범위부터 공개합니다. 현재 공개 본문은 창세기 1:1–2:25입니다.

## 번역의 출발점

구약에서는 **KJV 1769 표준 영문 본문과 그 기초가 된 마소라 본문(Masoretic Text, MT) 전통을 함께 일차적 번역 기준**으로 삼고, 공개된 [Westminster Leningrad Codex(WLC)](../../source-texts/wlc/index.md)를 주요 히브리어 참조 자료로 사용합니다. 원어의 문법·어휘·문맥이 허용하면 KJV의 선택을 가급적 따르며, 충분한 이유가 있을 때 다른 번역을 채택합니다. 의미가 실질적으로 충돌하면 원어 본문을 우선합니다. 다만 **칠십인역(Septuagint, LXX)**과 **사해사본(Dead Sea Scrolls, DSS)**이 의미 있는 다른 독법을 전한다면 해당 구절의 문맥, 원어와 사본 증거를 비교하여 판단하겠습니다. 예를 들어 신명기 32:8처럼 서로 다른 본문 전통의 차이가 해석에 영향을 주는 곳은 주요 대안과 판단 근거를 기록합니다.

본문에 대한 해석과 번역을 혼동하지 않도록, KJV의 표현과 다른 히브리어 독법을 반영한 제안 번역은 구별하겠습니다. 승인된 소단원부터 **번역 범위, 책별 버전, 중요한 수정 내역 및 관련 주석**을 연결할 예정입니다.

!!! info "책별로 천천히 공개합니다"
    구약 전체의 완성 일정이나 번역 순서를 미리 확정하지 않았습니다. 각 책의 본문을 충분히 검토하고 승인한 뒤 공개하며, 영어 KJV 읽기용 편집본과 한국어 번역문은 독립적인 버전과 편집 기록으로 관리합니다.

[번역 원칙](../principles.md) · [신약성경 번역 목록](../new-testament/index.md) · [성경 해석의 원칙](../../commentary/principles.md)

개별 성경책 페이지의 언어 선택을 통해 승인된 한국어 번역문과 영문 KJV 읽기용 편집본을 읽을 수 있습니다. 두 자료의 번역·편집 이력은 구별하여 관리합니다.
