# 번역 원칙 — 작업안

이 문서는 신약성경 번역 프로젝트의 **잠정적인 작업 원칙**입니다. 실제 번역 과정에서 문제가 확인되면 이유와 함께 수정할 수 있습니다.

## 1. 번역 저본과 대조 자료

- **기본 저본:** KJV 1611 번역 전통. 실무적으로 사용하는 표준 철자판(1769 계열)과 1611년 초판을 구별하며, 필요한 곳에서 판본 차이를 확인합니다.
- **한국어 비교 번역:** 표준킹제임스성경, 말씀보존학회 한글킹제임스성경, 킹제임스 흠정역을 해석 비교에 활용합니다.
- **한국어 문체:** 개역한글판(1961)의 고전적이고 장중한 문체를 참고하되, 번역문은 독립적으로 작성합니다.
- **그리스어 참고 자료:** [Blue Letter Bible](https://www.blueletterbible.org/)의 TR(Stephanus 1550)을 우선 참고하며, KJV와 TR의 중요한 차이는 별도로 검토합니다.

KJV와 그리스어 원문은 같은 것이 아니므로 구분합니다. 원어 문법과 용례는 실제 해석상 문제가 있을 때 집중적으로 확인하되, 한 단어의 사전적 의미만으로 구절을 번역하지 않습니다.

## 2. 번역과 문체

- KJV를 먼저 독립적으로 번역한 뒤 한국어 참고 역본과 비교합니다.
- KJV의 장중함을 살리면서도 현대 독자가 의미를 이해할 수 있는 한국어를 지향합니다.
- 의미상 연결된 문장들을 문단으로 묶고, 장·절 번호는 유지합니다.
- 화자의 직접 발언에는 큰따옴표를 사용합니다. 발화의 경계가 논쟁적인 경우 이를 편집적 판단으로 기록합니다.
- 기존 번역과의 차이가 곧 오류를 뜻하는 것은 아니며, 합리적인 복수의 해석이 있으면 기록합니다.

## 3. 검토 및 버전 관리

- 각 내용 단위는 **AI 초안 → 사용자 검토 및 대화 → 승인된 통합본** 순서로 진행합니다.
- 각 책을 별도 Markdown 파일로 관리하고, 책별 버전과 공개 범위를 명시합니다.
- 중요한 번역 선택에는 근거·대안·불확실성을 기록합니다.
- 외부의 비판과 제안이 타당하다면 번역을 변경하고, 변경하지 않은 중요한 반론도 판단 근거와 함께 보존합니다.
- 외부에 공개된 이전 버전은 GitHub의 버전 관리 기능을 통해 추적할 수 있도록 합니다.
