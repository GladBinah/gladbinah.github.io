# 성경 번역

**KJV 한국어 신약 번역 · 공개 검토 · 지속적인 개정**

이 프로젝트는 상업적 목적 없이 자유롭게 읽고 활용할 수 있는 한국어 KJV 번역문의 필요성에서 시작되었습니다. 우선 신약성경을 책별로 번역하며, 번역문과 검토 근거를 Markdown으로 보존하고 공개할 계획입니다.

## 작업 현황

현재는 번역 원칙과 공개 웹사이트를 준비하는 단계입니다. **아직 승인·공개된 번역 본문은 없습니다.** 최초 번역이 승인되면 [신약성경 목록](books/index.md)에 책별 버전과 함께 게재합니다.

## 작업 방식

1. 각 내용 단위의 KJV 영어 본문을 바탕으로 한국어 초안을 작성합니다.
2. 기존 한국어 KJV 번역들과 비교하고 문체·의미·문단과 인용 경계를 검토합니다.
3. 필요할 때 [Blue Letter Bible](https://www.blueletterbible.org/)의 Stephanus TR 계열 그리스어 본문과 용례를 참고합니다.
4. 토론과 검토를 거쳐 본문을 확정하고 해당 책의 Markdown 파일에 누적합니다.
5. 책별 버전 및 중요한 번역 결정과 외부의 비판·수정 사항을 기록합니다.

AI는 초안 및 비교·검토를 돕는 도구로 사용하며, 최종 번역 결정은 사람이 검토합니다. 번역의 완전성이나 무오류성을 주장하지 않습니다.

## 이용 조건과 공개 목표

최종적으로 독립적인 한국어 번역문을 **CC BY-NC 4.0**으로 공개하는 것을 목표로 합니다. 다만 번역문의 권리 귀속과 공개 범위는 최종 공개 전에 확인하고, 실제 배포되는 각 자료에 정확한 라이선스를 표시하겠습니다. 다른 번역본의 저작권까지 이 라이선스에 포함하는 것은 아닙니다.

## 질문과 수정 제안

중요한 번역 선택에 관한 근거와 수정 이력을 함께 공개할 계획입니다. [GitHub Issues](https://github.com/GladBinah/gladbinah.github.io/issues)를 통해 질문과 수정 의견을 받을 수 있도록 안내하겠습니다.
