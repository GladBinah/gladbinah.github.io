# KJV 한글성경: 신약

신약성경의 독립 한국어 번역을 책별로 차례로 공개하는 공간입니다. 번역은 KJV 1769 표준 영문 본문과 그 기초 그리스어 본문 전통을 함께 일차적 기준으로 삼아 검토하며, 의미 있는 번역 선택은 별도 기록에 설명합니다.

**현재 승인·공개된 번역 본문은 없습니다.** 첫 본문이 승인되면 성경책별 번역문, 공개 장절 범위, 버전 및 번역 결정 기록을 이곳에 연결하겠습니다.

개별 성경책 페이지에서는 향후 **한국어/English 언어 선택**으로 독립 한국어 번역과 승인된 KJV 영문 읽기용 편집본을 각각 볼 수 있도록 구성할 계획입니다. 두 본문은 별도로 검토하고 버전을 관리합니다.
