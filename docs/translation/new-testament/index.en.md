# KJV Korean Bible: New Testament

This section will publish the project's independently prepared Korean New Testament, book by book, with passage coverage, book-specific versions, and translation decision notes.

**No translation passages have yet been approved for publication.** Once a biblical book is available, the Korean-language view will show the Korean translation, while the English-language view will show the approved edited KJV reading text. These two versions are reviewed and maintained separately.
