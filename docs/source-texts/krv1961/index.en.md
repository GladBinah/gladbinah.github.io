# Korean Revised Version (1961) — Reference Bible

The **1961 Korean Revised Version (개역한글판)** is available here by book. It is a reference text, distinct from the independent Korean translation prepared by Together Before Scripture.

**Source:** Korean Bible Society, *성경전서 개역한글판* (1961) · [Copyright information](https://www.bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=5)

**Coverage:** 66 books · 1,189 chapters · 31,101 verse entries in this reference text
