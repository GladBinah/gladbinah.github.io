# King James Version (1769) — Reference Text

This book-by-book reference presents the **standard-spelling King James Version, commonly associated with the 1769 edition**. It is distinct from the original 1611 printing and from our separately prepared **English KJV Reading Edition**.

**Text source:** [renniemaharaj/kjv-bible](https://github.com/renniemaharaj/kjv-bible)

**Coverage:** 66 books · 1,189 chapters · 31,102 verses
