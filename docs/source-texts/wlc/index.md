# 마소라 본문 — Westminster Leningrad Codex

구약성경의 히브리어·성서 아람어 **마소라 본문**을 책별로 제공합니다. 이 전자 본문은 레닌그라드 사본에 기반한 **Westminster Leningrad Codex(WLC)**이며, KJV 번역자들이 직접 사용한 히브리어 인쇄본과 동일한 판본이라는 뜻은 아닙니다.

**본문 출처:** [Open Scriptures Hebrew Bible](https://github.com/openscriptures/morphhb) (WLC: 퍼블릭 도메인). 형태 분석 데이터는 싣지 않았습니다.

**장절 번호:** 마소라 본문 자체의 번호를 유지합니다. KJV의 장절 번호와 다른 부분이 있으며, 임의로 변환하지 않았습니다.

**표기:** 모음부호와 전통적 악센트를 보존합니다. Ketiv/Qere는 해당 성경책 하단에 구별해 기록합니다.

**수록 범위:** 39권 · 929장 · 23,213절
