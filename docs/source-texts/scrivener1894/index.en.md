# Scrivener 1894 — Greek New Testament

Read the **1894 Textus Receptus edited by F. H. A. Scrivener**, presented book by book. This is a later reconstruction of the Greek text underlying the KJV, not a single edition used by the KJV translators in 1611.

**Text source:** [honza/textus-receptus](https://github.com/honza/textus-receptus) · [1894 printed edition](https://archive.org/details/textusreceptus/page/7/mode/2up)

**Coverage:** 27 New Testament books · 260 chapters · 7,957 verses
